# MikuPlay Reburn 插件开发规范

## 一、插件类型

| 类型 | mount 位置 | 用途 |
|---|---|---|
| `ui` | 底部 Tab 栏 / 侧边栏 | 控制面板类插件 |
| `postproc` | 后处理面板 | 后处理效果类插件 |
| `functional` | 功能模块 | 地面、粒子、材质等功能扩展 |

## 二、VMD 动作 API

**位置**：`src/features/mmd/VmdApiService.ts`  
**全局单例**：`vmdApiService`

### 初始化
```typescript
import { vmdApiService } from './features/mmd/VmdApiService';

// 在主程序启动时调一次
vmdApiService.setAnimationManager(animationManager);
```

### 接口列表

#### 1. parseVmd(filePath: string)
解析 VMD 文件，返回 MmdAnimation 对象。
```typescript
const anim = await vmdApiService.parseVmd('/path/to/action.vmd');
```

#### 2. getAnimationInfo(animation)
获取动画摘要：
```typescript
interface VmdAnimationInfo {
    name: string;
    type: 'motion' | 'camera';
    boneNames: string[];    // 所有骨骼名
    morphNames: string[];   // 所有形变名
    maxFrame: number;       // 最大帧号
}
```

#### 3. getBoneFrames(animation, boneName)
获取指定骨骼的所有帧数据：
```typescript
interface VmdBoneFrame {
    frame: number;
    position: { x, y, z };
    rotation: { x, y, z, w };  // 四元数
}
const frames = vmdApiService.getBoneFrames(anim, '全ての親');
```

#### 4. getMorphFrames(animation, morphName)
获取指定形变的所有权重帧：
```typescript
interface VmdMorphFrame {
    frame: number;
    weight: number;  // 0~1
}
```

#### 5. getCameraFrames(animation)
获取镜头动画的所有帧：
```typescript
interface VmdCameraFrame {
    frame: number;
    position: { x, y, z };
    rotation: { x, y, z };
    distance: number;
    fov: number;
}
```

#### 6. setBoneFrame(animation, boneName, frameIndex, data)
修改/新增骨骼帧：
```typescript
vmdApiService.setBoneFrame(anim, '全ての親', 30, {
    position: { x: 10, y: 0, z: 0 },
    rotation: { x: 0, y: 0, z: 0, w: 1 }
});
```

#### 7. setMorphFrame(animation, morphName, frameIndex, weight)
修改/新增形变帧：
```typescript
vmdApiService.setMorphFrame(anim, '笑い', 30, 0.8);
```

#### 8. listLoadedAnimations()
列出当前已加载的所有动画：
```typescript
const list = vmdApiService.listLoadedAnimations();
// [{ id: 'xxx', name: 'action.vmd', modelId: 'model_1' }]
```

#### 9. loadAnimationToModel(filePath, fileName, modelId)
加载 VMD 到指定模型：
```typescript
await vmdApiService.loadAnimationToModel('/path/to/action.vmd', 'action.vmd', 'model_1');
```

## 三、粒子系统 API

**位置**：`src/features/particle/ParticleApiService.ts`  
**全局单例**：`particleApiService`

### 初始化
```typescript
import { particleApiService } from './features/particle/ParticleApiService';

particleApiService.setParticleManager(particleManager);
```

### 接口列表

#### 1. registerPreset(def: ParticlePresetDefinition)
注册自定义粒子预设：
```typescript
particleApiService.registerPreset({
    type: 'myplugin.sparkle',
    name: '自定义星光',
    defaultParams: {
        emitterPosition: new Vector3(0, 10, 0),
        emitRate: 100,
        minSize: 0.5,
        maxSize: 2.0
    },
    renderConfig: {
        textureSource: 'custom',
        texture: 'data:image/...',  // 或 URL
        blendMode: 'oneOne',
        depthWrite: false,
        enableRotation: true,
        defaultMaxParticles: 1000
    },
    adjustableParams: [
        { key: 'emitRate', label: '发射速率', min: 0, max: 500, step: 10, default: 100 }
    ]
});
```

#### 2. createSystem(pluginId, name, params, renderConfig)
创建粒子系统：
```typescript
particleApiService.createSystem(
    'com.myplugin',
    'my_sparkle',
    { emitterPosition: new Vector3(0, 10, 0), emitRate: 100 },
    { textureSource: 'custom', texture: '...', blendMode: 'oneOne', ... }
);
```

#### 3. updateParams(name, params)
更新粒子系统参数：
```typescript
particleApiService.updateParams('my_sparkle', { emitRate: 200 });
```

#### 4. setEnabled(name, enabled)
启用/禁用：
```typescript
particleApiService.setEnabled('my_sparkle', false);
```

#### 5. removeSystem(name)
移除粒子系统：
```typescript
particleApiService.removeSystem('my_sparkle');
```

#### 6. getSystemState(name)
获取系统状态：
```typescript
interface ParticleSystemInfo {
    name: string;
    type: string;
    enabled: boolean;
    particleCount: number;
    params: Partial<ParticleParams>;
}
```

#### 7. listSystems()
列出所有粒子系统：
```typescript
const systems = particleApiService.listSystems();
```

#### 8. listPresets()
列出所有已注册的预设：
```typescript
const presets = particleApiService.listPresets();
```

#### 9. loadCustomTexture(source, name?)
加载自定义纹理：
```typescript
// 从 URL
const { url, name } = await particleApiService.loadCustomTexture('https://example.com/star.png');

// 从 File 对象
const input = document.createElement('input');
input.type = 'file';
input.accept = 'image/*';
input.onchange = async () => {
    const file = input.files[0];
    const { url, name } = await particleApiService.loadCustomTexture(file);
};
```

#### 10. replaceTexture(systemName, textureUrl)
替换现有系统的纹理：
```typescript
particleApiService.replaceTexture('my_sparkle', 'https://example.com/new-star.png');
```

#### 11. on(event, callback) / off(event, callback)
事件监听：
```typescript
particleApiService.on('systemCreated', (data) => {
    console.log('粒子系统创建:', data.name);
});
```

## 四、后处理 API

**位置**：`postProcessAdapterRegistry`  
**接口**：`IPostProcessAdapter`

### 注册后处理适配器
```typescript
import { postProcessAdapterRegistry } from './features/postproc/PostProcessAdapterRegistry';

class MyGlareAdapter implements IPostProcessAdapter {
    readonly typeId = 'myplugin.glare';
    readonly displayName = '我的辉光';
    readonly order = 25;  // Bloom 之后

    getControlDeclarations(): ControlDeclaration[] { ... }
    getDefaultState(): Record<string, ParamValue> { ... }
    readState(): Record<string, ParamValue> { ... }
    writeState(state: Record<string, ParamValue>): void { ... }
    initialize(scene: Scene, camera: Camera): void { ... }
    isInitialized(): boolean { ... }
    setEnabled(enabled: boolean): void { ... }
    isEnabled(): boolean { ... }
    dispose(): void { ... }
}

postProcessAdapterRegistry.register(new MyGlareAdapter());
```

## 九、最佳实践

1. **单例模式**：所有 Manager 都用单例，不要重复创建
2. **资源释放**：插件 dispose 时必须释放所有 Babylon 资源（mesh/material/texture/postProcess）
3. **错误隔离**：插件内部用 try/catch 包裹，不要让插件崩溃影响主程序
4. **性能注意**：粒子系统不要超过 5 个同时运行，后处理 pass 数控制在 10 以内
5. **内存管理**：自定义纹理用完后调用 `URL.revokeObjectURL()` 释放
